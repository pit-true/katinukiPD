# カチヌキPD

プロキオン・デネブ向けのダメージ計算Webアプリです。
両作品の習得技を1つの候補リストへ統合しています。

## 起動

JSONを読み込むため、ローカルHTTPサーバーから開きます。

```powershell
python -m http.server 8765
```

ブラウザで `http://127.0.0.1:8765/` を開いてください。

## 主な対応

- プロキオン・デネブ313体の種族値、タイプ、特性、体重、両作品の習得技
- 652技のタイプ、分類、威力、命中、効果範囲、ROM内説明文
- 技を選択したときの技情報・説明文表示
- 第6世代以降のタイプ相性とフェアリータイプ
- 第7世代準拠の急所1.5倍、壁、ダブル全体技、天候補正
- じばく・だいばくはつの防御半減なし
- 砂嵐中のいわタイプの特防1.5倍
- マルチスケイル、フィルター、ハードロック、各種スキン、テクニシャン、
  がんじょうあご、てつのこぶし、ちからずくなどのダメージ補正
- いのちのたま1.3倍（タイプ相性前）、VPD仕様のジュエル威力1.5倍、
  こだわり系、タイプ強化、半減実などの持ち物補正
- グラベルブレスの素早さ比威力、ライフエナジー・しぼりとるの相手HP比例威力
- アクロバット、しおみず、ソウルシェイプ、かじばのいちげき、ダイナソードの条件付き威力
- イカサマ、ワイルドカード、バリアアタックと、防御・特防を入れ替えて参照する特殊技
- カラフルアタックの使用者タイプ化（ギャラクシアはどく、カクレオンはノーマル）
- ソウルブレイクの壁貫通
- クイックターン、バリアブラスト、しっぺがえしのROM準拠2倍・失敗条件
- アシストパワー、おしおき、デッドリーボーンのROM準拠変動威力

対象技を選ぶと、技欄の下に必要な能力ランクや条件だけが表示されます。

## テスト

Node.js 20以降で実行します。

```powershell
npm test
```

計算コアの第7世代準拠ルールを `node:test` で検証しています。

## 構成

- `index.html`: 画面
- `style.css`: レイアウト
- `script.js`: 入力、候補検索、複数ターン計算、結果表示
- `damage_core.js`: タイプ相性・特性・持ち物を含むダメージ計算コア
- `all_pokemon_data.json`: プロキオン・デネブ統合ポケモンデータ
- `pokemon_moves.json`: 技データと技説明
- `item.json`: 持ち物データ

ROM本体、ROM抽出ツール、パッチャー関連ファイルはこのリポジトリに含めません。
