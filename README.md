# カチヌキPD

プロキオン・デネブ向けのダメージ計算Webアプリです。
ポケモン、技、能力値、持ち物、特性、場の状態などを指定して、
ダメージ範囲や相手を倒せる確率を計算できます。

## Web版

**[カチヌキPDを開く](https://pit-true.github.io/katinukiPD/)**

インストールは不要です。ブラウザからそのまま利用できます。

## 使い方

1. 攻撃側と防御側のポケモンを選択します。
2. レベル、能力値、性格、努力値などを設定します。
3. 使用する技と持ち物、特性を選択します。
4. 必要に応じて天候、壁、能力ランクなどの条件を設定します。
5. ダメージ計算ボタンを押すと、ダメージ範囲と瀕死率が表示されます。

技を選択すると、その技で必要になる固有条件だけが画面に表示されます。

## 主な対応内容

- プロキオン・デネブのポケモン313種
- 両作品の習得技を統合した技候補
- 技652種のタイプ、分類、威力、命中率、効果範囲、説明文
- 第6世代以降のタイプ相性とフェアリータイプ
- 第7世代準拠の急所、壁、天候、ダブルバトル補正
- 特性、持ち物、タイプ一致、タイプ相性、半減実の補正
- 連続攻撃、定数ダメージ、回復を含む複数ターン計算
- プロキオン・デネブ独自技の威力計算と発動条件

独自技では、グラベルブレス、ライフエナジー、ソウルシェイプ、
カラフルアタック、ソウルブレイク、クイックターン、
バリアブラスト、デッドリーボーンなどに対応しています。

## 注意事項

- 計算結果は対戦時の参考値として利用してください。
- 複数の特殊効果が重なる状況では、実際のゲーム内結果と異なる場合があります。
- ROMファイルを選択したり、アップロードしたりする必要はありません。
- 本ツールは非公式のファン制作ツールです。
